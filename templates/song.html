Leave blank to keep the written key. Moves the chart, the chord spellings and every diagram together. Needs a starting key above (or a {key:} directive) to know how to spell the result — note that Gb and F# are the same key but spell the chords differently.
Definitions are now optional. Chord symbols in the changes are read directly — Abm7, Ab-7, D9, D7add9, G#7(b9#11), C6/9, Cø, C7alt and the rest all spell themselves. Write a definition only to override one, or for a symbol the parser cannot read.

Definitions — Name: note note note ..., spelled low to high. Use b for flat, # for sharp (e.g. Ab, C#, Bbb). Append : 0 1 2 for specific inversions (0=root, 1=first, …). The fifth can be omitted for jazz voicings. These drive the diagrams.

Changes (optional, for the lead sheet) — bars between | pipes. Chords in a bar split it evenly, so | Dm7 G7 | is two beats each. / adds a beat to the chord before it (| Cmaj7 / / A7 | is 3+1), % repeats the previous bar, |:…:| marks a repeat, and || or |] ends a section. |1 and |2 open first and second endings inside a repeat (|: Am7b5 | D7 |1 Gm6 :| then |2 Cm7 |]) — an ending runs until the next ending marker, a :|, a double bar, or a new {section:}, so it can span more than one line. Close it with || if the tune carries on after it. A chord in the changes with no definition still prints — it just gets no diagram.

Directives (optional) — {title:}, {composer:}, {key:}, {time:}, {tempo:}, {section:}, {transpose:}. The fields above win over a directive; {time:}, {tempo:} and {section:} can also appear between bars to change mid-tune.
